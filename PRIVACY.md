# ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ MUSICHUB

**Версия 1.0 | Последнее обновление: 02.08.2026**

---

1. ОБЩИЕ ПОЛОЖЕНИЯ

MusicHub — это десктопное приложение для прослушивания музыки, которое объединяет несколько стриминговых сервисов в одном окне. Мы НЕ собираем, НЕ храним и НЕ передаём ваши личные данные третьим лицам. Приложение работает полностью локально на вашем компьютере.

---

2. КАКИЕ ДАННЫЕ МЫ НЕ СОБИРАЕМ

Мы принципиально не собираем следующие данные:

- Имя, фамилия, email, номер телефона
- Пароли от каких-либо сервисов
- Токены доступа к API
- Банковские карты и платёжные данные
- IP-адрес (приложение локальное)
- Геолокация
- История браузера
- Любые другие персональные данные

---

3. КАКИЕ ДАННЫЕ ХРАНЯТСЯ ЛОКАЛЬНО

Все данные хранятся ТОЛЬКО на вашем компьютере в папке пользователя и НИКУДА НЕ ПЕРЕДАЮТСЯ.

Перечень локально хранимых данных:

- Настройки приложения (тема, акцентный цвет, громкость) — для сохранения ваших предпочтений
- История прослушивания — для статистики
- Статистика (количество треков, исполнителей, время прослушивания) — для отображения вашей активности
- Список активных сервисов и кастомных сайтов — для быстрого доступа
- Настройки горячих клавиш — для управления плеером
- Настройки Discord RPC — для отображения статуса (опционально)

Все эти данные хранятся в localStorage браузера и в файле config.json в папке пользователя. Вы можете удалить их в любой момент вручную через проводник, удалив папку приложения в %APPDATA%/MusicHub.

---

4. РАБОТА СО СТРИМИНГОВЫМИ СЕРВИСАМИ

ВАЖНО: MusicHub НЕ ИСПОЛЬЗУЕТ API стриминговых сервисов. Приложение работает через встроенный браузер (webview), который просто открывает сайты сервисов внутри себя.

Список поддерживаемых сервисов и способ работы:

Яндекс Музыка — встроенный браузер (webview) — данные не передаются
YouTube Music — встроенный браузер (webview) — данные не передаются
SoundCloud — встроенный браузер (webview) — данные не передаются
Spotify — встроенный браузер (webview) — данные не передаются
VK Music — встроенный браузер (webview) — данные не передаются
Кастомные сайты — встроенный браузер (webview) — данные не передаются

Как это работает:
- Вы входите в свой аккаунт напрямую в сервисе через встроенный браузер
- MusicHub не видит ваши логин и пароль
- MusicHub не перехватывает и не хранит ваши токены
- Музыка воспроизводится на сайте сервиса через webview
- Все данные авторизации остаются в браузере сервиса

---

5. ОБМЕН ДАННЫМИ ЧЕРЕЗ ИНТЕРНЕТ

MusicHub отправляет данные в интернет только в следующих случаях:

- AI-запросы к GigaChat — отправляются на сервер Sberbank GigaChat API для работы чат-бота (опционально, только если вы используете AI-чат)
- Запрос поиска в YouTube Music (по команде из AI-чата) — отправляется на YouTube Music для поиска песен
- Discord Rich Presence (опционально) — отправляет информацию о текущем треке в Discord

Все остальные данные остаются локально и никуда не передаются.

---

6. AI-ЧАТ

- Все запросы к AI обрабатываются анонимно
- История диалога хранится локально и используется только для контекста беседы
- Мы не сохраняем историю чата на серверах
- AI-чат можно не использовать — достаточно просто не открывать его

---

7. АУДИО И МИКРОФОН

- Визуализации — анализ звука с сайта или микрофона, данные не сохраняются
- Адаптивная громкость — анализ шума через микрофон, данные не сохраняются (опционально, включается в настройках)

Все аудиоданные обрабатываются исключительно локально на вашем компьютере и НЕ передаются на сервер.

---

8. DISCORD RICH PRESENCE (RPC)

Если вы включаете Discord RPC в настройках приложения:

- MusicHub отправляет в Discord только информацию о текущем треке (название и исполнитель)
- Никакие данные о вас не передаются и не хранятся
- Вы можете отключить эту функцию в любой момент в настройках

---

9. МОБИЛЬНОЕ УПРАВЛЕНИЕ

- Подключение происходит только через локальную сеть (Wi-Fi)
- Данные не выходят в Интернет
- Управление возможно только с устройств в вашей сети
- QR-код генерируется локально и содержит только IP-адрес вашего компьютера

---

10. ЗАПРЕЩЁННОЕ ИСПОЛЬЗОВАНИЕ

Запрещается использовать MusicHub для следующих целей:

- Попытки взлома или несанкционированного доступа к сервисам
- Внедрение вредоносного кода через webview
- Перехват данных пользователей сервисов
- Использование приложения в коммерческих целях без разрешения автора
- Любые другие действия, нарушающие законодательство

---

11. БЕЗОПАСНОСТЬ

- MusicHub работает локально и не требует подключения к нашим серверам
- Все данные шифруются только локально (браузерное хранилище)
- Мы не имеем удалённого доступа к вашим данным
- Приложение не содержит шпионских модулей

---

12. ВАШИ ПРАВА

Вы имеете право:

- Использовать MusicHub без регистрации и без предоставления каких-либо данных
- Удалить все локальные данные в любой момент вручную через проводник (папка %APPDATA%/MusicHub)
- Выключить Discord RPC и адаптивную громкость в настройках
- Полностью удалить приложение с вашего компьютера
- Не использовать приложение вообще
