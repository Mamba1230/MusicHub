## 🚀 О проекте

**MusicHub** — это десктопный музыкальный плеер-агрегатор, который объединяет несколько стриминговых сервисов в одном окне. С визуализациями, чатом с AI, поддержкой расширений и полной кастомизацией интерфейса.

> ⚠️ **Важное предупреждение:** проект полностью создан при помощи вайбкодинга (нейросети). Некоторые участки кода могут вызывать желание переписать, но оно работает. Не судите строго 🙃

Проект активно развивается. Если вам интересны версии до 2.4.0, знайте, что первой стабильной стала `1.7.1`. Более старые версии не выкладывались в сеть из-за проблем с производительностью.

## ✨ Возможности

### 🎵 Музыкальные сервисы
- **Поддерживаемые сервисы**: Яндекс Музыка, YouTube Music, SoundCloud, Spotify, VK Music.
- **Мультизадачность**: До 2 сервисов одновременно (можно выбрать любые).
- **Кастомные сайты**: Добавляйте любые музыкальные URL.

### 🎨 Визуализации (10+ режимов)
- **Базовые**: Полоски, Волна, Круг, Частицы.
- **GIF**: Своя анимация, реагирующая на музыку.
- Полноэкранный режим с переключением эффектов.

### 🎤 Захват звука
- Выбор микрофона или Virtual Audio Cable.
- Реальная реакция визуализаций на громкость.
- Регулируемая чувствительность.

### 🧠 Искусственный интеллект нового поколения
Интеграция с GigaChat (Сбер). Нейросеть теперь не просто болтает — она управляет музыкой!

**🎯 Команды AI:**
- `найди [песня]` — открывает поиск в YouTube Music.
- `включи музыку` / `выключи музыку` — Play / Stop.
- `следующий трек` / `предыдущий трек` — Next / Prev.
- `сделай погромче` / `сделай потише` / `установи громкость 50` — Управление громкостью.

**📚 Что умеет AI:**
- **База знаний**: Информация об исполнителях, жанрах, фактах.
- **Понимание контекста**: Помнит, о ком говорили ранее.
- **История диалога**: Помнит последние 10 сообщений.

**💬 Команды чата:** `/ai`, `/clear`, `/coin`, `/help`.  
**Premium** открывает безлимитные запросы.

### 📱 Мобильное управление (CarPlay-интерфейс)
**НОВИНКА в версии 3.0.0!** Управляйте музыкой прямо с телефона.
- **QR-код в настройках**: Наведи телефон — и всё готово.
- **Крупные кнопки**: Удобно нажимать на ходу.
- **Обложка трека** в реальном времени.
- **Горизонтальный режим**: Обложка слева, управление справа.
- **Акцентный цвет** синхронизируется с приложением.
- **WebSocket**: Мгновенное обновление статуса.

### ⌨️ Гибкие горячие клавиши
Теперь вы сами решаете, какие клавиши использовать!

**По умолчанию:**
| Комбинация | Действие |
|------------|----------|
| `Ctrl+Shift+Space` | Play/Pause |
| `Ctrl+Shift+→` | Следующий трек |
| `Ctrl+Shift+←` | Предыдущий трек |
| `Ctrl+Shift+.` | Стоп |
| `Ctrl+Shift+↑` | Громче |
| `Ctrl+Shift+↓` | Тише |

**Настройка:** Перейдите в Настройки → Горячие клавиши → нажмите "Изменить" и введите новую комбинацию. Поддерживаются: буквы, цифры, стрелки, Numpad, F-клавиши, медиа-клавиши!

### 🎨 Интерфейс и управление
- **Тёмная и светлая темы**.
- **Акцентный цвет** (любой на выбор).
- **Стиль кнопок окна**: macOS / Windows (переключается).
- **Регулируемый масштаб**: 80% / 100% / 120%.
- **Мини-режим**: Окно поверх всех окон.
- **Эффекты кнопок**: Пульсация / Свечение.
- **Навигация** `◀ ▶` в тайтлбаре.
- Клик по URL — копирует ссылку.
- Домашняя страница с крупными кнопками управления: **▶/⏸**, **⏹**, **⏭**, **⏮**, ползунок громкости.

### 🔊 Новый C# модуль управления звуком (начиная с v2.9.7)
Полностью переработанный VolumeController:
- **Захват звука без VB-Cable**: Напрямую через WASAPI.
- **Передача аудиопотока** в реальном времени через WebSocket.
- **Определение Play/Pause по звуку**: Автоматическая синхронизация.
- **Умное управление громкостью** для всех аудио-сессий.
- **Медиакоманды**: Play/Pause/Next/Prev в систему.

## 📦 Установка

```bash
# Клонируем репозиторий
git clone https://github.com/Mamba1230/musichub.git
cd musichub

# Устанавливаем зависимости
npm install

# Запускаем
npm start
```

### Системные требования
- **Windows 10** или новее
- **4 ГБ ОЗУ**
- **~600 МБ** свободного места (для версии 3.0.5)
