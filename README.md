# 🎵 MusicHub

Музыкальный плеер с визуализациями. Поддерживает Яндекс Музыку, YouTube Music и кастомные сайты.

## ✨ Возможности

- 🎵 **Музыкальные сервисы**: Яндекс Музыка, YouTube Music, SoundCloud, Spotify, VK Music (и ваши кастомные сайты)
- 🎨 **25+ визуализаций**: Полоски, Галактика, 3D Туннель, GIF анимация и другие
- 🖥️ **Режим поверх всех окон** (мини-режим)
- 💎 **Premium**: Все визуализации, безлимитный AI, кастомные сайты
- 💬 **AI-чат** с командами `/ai`, `/clear`, `/coin`

## 🚀 Установка

### Готовый установщик
1. Скачай последнюю версию из [Releases](https://github.com/Mamba1230/MusicHub/releases)
2. Запусти `MusicHub-Setup-2.4.0.exe`
3. Следуй инструкциям установщика

### Из исходников
```bash
git clone https://github.com/Mamba1230/MusicHub.git
cd MusicHub
npm install
npm start
