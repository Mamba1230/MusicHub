# Политика безопасности

## Поддерживаемые версии

Мы выпускаем обновления безопасности для следующих версий MusicHub:

| Версия | Поддерживается |
| ------- | ------------------ |
| 3.3.x   | ✅ Да              |
| 3.2.x   | ⚠️ Только критические |
| < 3.2   | ❌ Нет             |

## Сообщение об уязвимости

Если вы нашли уязвимость в MusicHub, **пожалуйста, не создавайте публичный Issue**.

Вместо этого напишите на email: **MusicHubSupport@gmail.com**

### Что указать в сообщении

- Описание уязвимости
- Шаги для воспроизведения
- Версия MusicHub
- Версия Windows
- Скриншоты / видео (если есть)

### Что мы гарантируем

- Ответ в течение **48 часов**
- Подтверждение получения уязвимости
- План исправления
- Упоминание вас в списке благодарностей (если хотите)

## Что НЕ считается уязвимостью

- Баги, не связанные с безопасностью (создавайте обычный Issue)
- Проблемы с производительностью
- Неправильный перевод / опечатки
- Фичи, которые вы хотели бы видеть
